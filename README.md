# 📚 ConsoleBookManager

A console-based library management system built with **.NET** and **EF Core**. Keep track of your reading progress, calculate daily goals, and manage your personal book collection with a clean, interactive UI.

## ✨ Features

- **Inventory Management:** Full CRUD operations (Create, Read, Update, Delete) for your books.
- **Smart Progress Tracking:** Visualize your progress with dynamic progress bars and chapter tracking.
- **Reading Planner:** Automatically calculate daily page goals based on target completion dates.
- **2.5D ASCII Animations:** Immersive intro/outro animations (Library Shelf and Book Closing effects).
- **Persistent Storage:** Powered by Entity Framework Core for reliable data management.
- **Cross-Platform:** Ready for Windows and Linux (Debian 13 tested).
